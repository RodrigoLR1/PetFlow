# 📢Projeto - PetFlow/PetPanel - Projeto Integrador
Desenvolver uma plataforma web integrada a automações e inteligência artificial para otimizar o fluxo de comunicação entre pequenos pet shops e tutores, promovendo a transformação digital do negócio.

O **PetFlow/PetPanel** é uma plataforma web desenvolvida para digitalizar e
otimizar o fluxo de atendimento em pet shops de pequeno e médio porte,
com foco específico nos serviços de banho e tosa. O sistema atua como
um painel de controle interativo onde os funcionários podem atualizar o
status de cada animal em tempo real. A principal inovação do sistema é a
integração com mensageria automatizada e Inteligência Artificial. Ao
alterar o status de um pet no sistema, o tutor recebe notificações
automáticas. Além disso, a plataforma utiliza IA generativa para criar
legendas de redes sociais a partir de fotos dos animais e automatiza a
coleta de avaliações de satisfação pós-atendimento.
